
### Структура лабораторной
```
schem-I-almost-give-a-fuck  
|— src  
|  |— фигня.sv  
|  |— тестоваяскамейка.sv  
|  |— ... 10+ файлов мб, без разницы.  
|
|— sim
```

Для быстрой компиляции и запуска всякой хрени (схем), есть специальный скрипт `sim`. В консоли Vsim прописываем:
```
do sim <testbench-module-name>
```

И он, по идее, должен сразу тупо скомпилить и запустить фигню эту всю. Вооот.
